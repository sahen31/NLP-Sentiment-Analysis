# NLP-Based Sentiment Analysis of Online Reviews

## Project Overview

This project focuses on classifying online reviews into three sentiment categories:

- Positive
- Negative
- Neutral

## Dataset

The dataset contains **1,000 online reviews** from:

- Amazon
- Daraz
- Reddit
- YouTube Comments

## Methodology

The project includes:

1. Data preprocessing
2. TF-IDF feature extraction
3. Train-test split
4. Machine-learning model training
5. Model evaluation
6. Sentiment trend analysis

## Models Used

- Logistic Regression
- Multinomial Naive Bayes
- Linear SVM

## Evaluation

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

All three models achieved **1.00 Accuracy, Precision, Recall, and F1-score** on the test dataset.
